## 🏢 About the Project

**A&H IMPEX** is engineered as a B2B corporate digital portal for an established textile manufacturer and international exporter based in Faisalabad, Pakistan.

The platform is purpose-built to address the demanding procurement requirements of international retail buyers, hotel chain procurement heads, department store merchandisers, and institutional importers. It highlights end-to-end industrial capabilities, including:

- **Vertical Textile Manufacturing**: From ring-spun fiber sourcing and high-speed air-jet weaving to computerized reactive dyeing and precision unit stitching.
- **Home Textiles**: Luxury sateen and percale bed sets, duvet suites, and pillowcase collections ranging from 200 TC to 1000 TC.
- **Hospitality & Institutional Linen**: Chlorine-resistant, commercial-laundry-tested white linens and damask jacquard banquet napery.
- **Export Apparel**: High-density casual twill chinos, loopback French terry tracksuits, and fleece outerwear.
- **OEM & Private-Label Production**: Custom warp/weft greige formulations, lab-dip color matching, custom wash care labels, and store-ready packaging.
- **Quality Assurance & Traceability**: Transparent documentation of inspection regimes aligned with international standards.
- **Commercial Logistics**: Clear export market profiles, freight forwarding capabilities, and Incoterms compliance.
- **Procurement Inquiries (RFQ)**: Direct digital conversion channels connecting prospective buyers directly with the commercial export desk.

## 🎯 Business Goals

The website is strategically structured to achieve clear commercial objectives:

1. **Establish International Brand Authority**: Position the company alongside global textile manufacturing leaders with an editorial, industrial aesthetic.
2. **Present Technical Capabilities**: Clearly showcase shuttleless air-jet looms, wide-width finishing (up to 340 cm), and high-volume output (18M+ linear meters annually).
3. **Structured Product Taxonomy**: Enable commercial buyers to quickly evaluate fabric compositions, GSM, yarn counts, stitch densities, and MOQs across distinct product categories.
4. **Communicate Quality Discipline**: Detail the multi-stage quality control workflow from incoming raw yarn inspection through the ASTM D5430 4-Point System and AQL 1.5 final audit.
5. **Demonstrate Regulatory Compliance**: Present recognized certifications and social audit frameworks, maintaining clear transparency regarding document availability.
6. **Accelerate B2B Inquiry Velocity**: Remove friction between product discovery and inquiry through a dedicated RFQ modal, direct WhatsApp merchandiser links, and commercial email desks.

## ⚡ Key Features

### 🏛️ Corporate Experience
- **Industrial Visual Identity**: Deep navy backgrounds (`#060B18`, `#0A1224`) accented with champagne gold typography and subtle woven mesh overlays.
- **Sticky Glassmorphic Navigation**: Dynamic scroll-aware navigation bar with backdrop blur, brand monogram badge, and mobile drawer.
- **Hero Section with Ken Burns Motion**: Full-width ambient imagery with subtle CSS scale animations, verified trust badges, and floating metric highlights.
- **Corporate Heritage & Metric Counters**: Structured storytelling covering facility capacity, loom counts, annual yardage, and export footprint.

### 🛏️ Product Showcase & Technical Catalog
- **Category Filtering**: Instant switching between Home Textiles, Apparel & Garments, Hospitality & Dining, and OEM / Private Label.
- **Technical Specification Cards**: Detailed breakdowns displaying composition, thread count, GSM, finish, sizing options, MOQ, and production lead times.
- **Seamless RFQ Pre-Population**: Selecting any product card opens the quotation modal pre-filled with that specific product's category and technical specifications.

### 🏭 Manufacturing Process Timeline
- **5-Stage Interactive Workflow**:
  1. *Yarn Selection & Warping* (Ring-spun / combed yarn audit, high-tension creeling).
  2. *Air-Jet Weaving* (European & Japanese shuttleless looms up to 340 cm widths).
  3. *Dyeing & Finishing* (Pad-steam continuous dyeing, mercerizing, OEKO-TEX compliant dyestuffs).
  4. *Stitching & Detailing* (Computerized 10–12 SPI assembly, automated elastication).
  5. *Quality Inspection & Dispatch* (Light-table review, needle detection, seaworthy carton packing).

### 🔍 Quality Assurance Pipeline
- **6-Stage Quality Control Protocol**:
  1. *Incoming Raw Material QC* (Fiber length, Micronaire, yarn count verification).
  2. *Weaving Greige Inspection* (ASTM D5430 4-Point System, penalty score < 18 points / 100 sq yds).
  3. *Laboratory Physical & Wet Testing* (Delta-E < 0.8 color variance, ISO 105-C06 wash fastness).
  4. *In-Line Stitching Audit* (SPI balance, French seam integrity, dimensional checks).
  5. *Final AQL Audit* (ANSI/ASQ Z1.4 Level II sampling, AQL 1.5 Major / 4.0 Minor).
  6. *Pre-Shipment Metal Detection* (0.8mm ferrous calibration, container floor moisture check < 12%).

### 📜 Compliance & International Standards
- **Transparent Standards Showcase**:
  - **ISO 9001:2015**: Quality Management System across weaving, dyeing, and stitching.
  - **OEKO-TEX® Standard 100**: Product Class I & II human-ecological safety against harmful substances.
  - **amfori BSCI**: Social responsibility, fair compensation, and ethical workplace compliance.
  - **Sedex / SMETA**: 4-Pillar supply chain audit covering labor, health, safety, and business ethics.
  - **GOTS (Global Organic Textile Standard)**: Certified organic fiber handling and transaction certificate workflows.
  > *Verification Note*: In strict adherence to commercial compliance standards, formal certificates, audit dossiers, and scope documentation are furnished directly upon request for active procurement inquiries.

### 🌍 Global Export Corridors & Logistics
- **Market Breakdown**: Visual regional distribution covering the European Union (38%), North America (32%), United Kingdom (15%), Middle East & GCC (10%), and Oceania (5%).
- **Shipping Logistics**: FCL/LCL ocean freight from Karachi Port to premier destinations (Rotterdam, Hamburg, New York, Los Angeles, Felixstowe, Jebel Ali).
- **Incoterms Support**: Fully documented capability for FOB, CIF, CFR, DDP, and EXW shipment terms.

### 📬 Lead Generation & RFQ Conversion
- **Interactive Request for Quotation (RFQ) Modal**: Includes commercial volume tiers, destination port specification, category select, and technical requirement fields.
- **Submission Feedback**: Interactive submission confirmation with confetti animation.
- **Multiple Conversion Channels**: Dedicated WhatsApp merchandiser desk, direct export email, and quick-dial contact points.

## 📐 Architecture

The project adheres to a clean separation of concerns, decoupling UI presentation from commercial data modules:

```
src/
├── assets/          # Static assets (brand marks, vector logos, hero visual)
├── components/      # Modular, single-responsibility UI sections and dialogs
├── data/            # Structured business, product, and manufacturing datasets
├── App.css          # Minimal application styles
├── App.jsx          # Root page layout, section composition, and modal state management
├── index.css        # Tailwind directives, custom design tokens, and utility classes
└── main.jsx         # React application entry point and DOM mounting
```

### Architectural Principles
- **Data-Driven Presentation (`src/data/`)**: All business statistics, contact details, product catalogs, manufacturing steps, and compliance information live in typed JavaScript data structures. Content edits require zero modifications to JSX markup.
- **Atomic & Sectional Components (`src/components/`)**: Each section on the page operates independently with explicit prop contracts, minimizing component coupling.
- **Global Modal Orchestration (`App.jsx`)**: The RFQ modal is maintained at the root application layer, enabling any button or product card across the entire page to trigger the modal with contextual product pre-population.
- **Centralized Design Tokens (`src/index.css` & `tailwind.config.js`)**: Colors, typography, glassmorphism filters, and animations are defined globally for complete visual consistency.

## 🎨 Design System

### Visual Language
The website employs an **industrial, modern B2B corporate** design language. Rather than generic corporate templates, the palette draws inspiration from luxury textile weaves and heavy industrial looms.

### Color Palette
- **Midnight Navy (Background & Surface)**:
  - Deep Base: `#060B18` (`navy-950`)
  - Primary Surface: `#0A1224` (`navy-900`)
  - Card & Container Fill: `#0E1A33` (`navy-850`)
  - Border Accents: `#14254A` (`navy-800`) / `#1A305F` (`navy-750`)
- **Champagne Gold (Brand Accent & Highlights)**:
  - Primary Gold: `#C5A880` (`gold-500`)
  - Soft Gold Highlight: `#DAC196` (`gold-400`)
  - Pale Accent: `#E8D5B5` (`gold-300`)
  - Deep Bronze: `#8A6F48` (`gold-700`)
- **Emerald Accent (Compliance & Trust)**:
  - Trust Badges: `#10B981` (`emerald-500`) / `#059669` (`emerald-600`)
- **Neutral Typography**: High-contrast white (`#FFFFFF`) headings and muted slate (`#94A3B8`, `#CBD5E1`) body copy.

### Typography
- **Headings & Quantitative Metrics**: `Outfit`, sans-serif — Geometric letterforms that convey precision and scale.
- **Body & Technical Data**: `Inter`, sans-serif — High x-height ensuring effortless readability across specification tables.

### UI Styling Principles
- **Selective Glassmorphism**: Frosted glass containers (`backdrop-filter: blur(14px)`) bordered with subtle translucency (`rgba(255, 255, 255, 0.08)`).
- **Subtle Fabric Weave Mesh**: CSS-generated radial dot pattern (`.bg-fabric-weave`) providing subtle texture behind cards.
- **Micro-Interactions**: Hover elevation (`translateY(-4px)`), smooth border illumination, and responsive focus rings.

## 📱 Responsive Design

The interface is engineered with a mobile-first approach and fully validated across major viewport breakpoints:

- **Desktop (1280px - 1536px+)**: Full multi-column grid layouts, expanded specification tables, side-by-side hero metrics, and wide-screen manufacturing timelines.
- **Laptop (1024px - 1279px)**: Optimized 2-column cards, condensed navigation spacing, and proportional container widths.
- **Tablet (768px - 1023px)**: Responsive 2-column product grids, adapted timeline selectors, and responsive header elements.
- **Mobile (< 768px)**:
  - Dedicated slide-out navigation drawer with smooth Framer Motion transitions.
  - Single-column touch-friendly product cards.
  - Horizontally swipeable/scrollable category selectors.
  - Floating speed dial displaying compact icon triggers.
  - Full-screen scrollable RFQ modal with thumb-accessible action buttons.

## ♿ Accessibility

The website incorporates key accessibility principles for an inclusive user experience:

- **Semantic HTML5 Structure**: Proper landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`) to facilitate screen reader navigation.
- **Descriptive ARIA Attributes**: Includes `aria-label`, `aria-expanded`, and `aria-hidden` attributes on icons and interactive toggles.
- **Keyboard Navigation**: Interactive elements (buttons, links, form inputs) maintain clear, visible focus rings.
- **Color Contrast**: Main body text and technical specifications adhere to high-contrast standards against dark navy backgrounds.
- **Secure External Links**: All external hyperlinks (WhatsApp, social media) include `rel="noopener noreferrer"` and `target="_blank"`.
- **Reduced Motion Support**: Incorporates a `@media (prefers-reduced-motion: reduce)` rule that disables intensive keyframe animations for users who prefer minimal motion.

*(Note: While developed adhering to modern accessibility guidelines, official third-party WCAG certification has not been commissioned.)*

## 🚀 Performance & UX

- **Vite Build Optimization**: Generates optimized production bundles with code splitting and minified CSS/JS.
- **Graceful Image Handling**: The bespoke `SafeImage` component provides:
  - Native lazy loading (`loading="lazy"`) and asynchronous image decoding (`decoding="async"`).
  - Background skeleton pulse loader preventing layout shifts (CLS).
  - Secondary fallback image support if the primary CDN asset is unreachable.
  - Branded fallback placeholder card if all image requests fail.
- **CSS-Powered Animations**: Ken Burns zoom, slow float, and subtle pulse animations run entirely via GPU-accelerated CSS keyframes rather than heavy JavaScript loops.
- **Fast Client-Side Filtering**: Category filtering occurs instantly in memory without additional network round trips.

## 💻 Installation & Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version `18.0.0` or higher recommended)
- `npm` (version `9.0.0` or higher)

### Setup Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AreebaSaleem95/A-H-IMPEX-website.git
   cd A-H-IMPEX-website
   ```

2. **Install project dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to:  
   👉 **`http://localhost:5173`**

4. **Run static code analysis (Linter)**:
   ```bash
   npm run lint
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```
   The compiled, production-ready assets will be generated in the `dist/` directory.

6. **Preview the production build locally**:
   ```bash
   npm run preview
   ```

## 🌐 Deployment

The application compiles into static HTML, JavaScript, and CSS assets and can be hosted on any modern static hosting service:

- **Vercel**: Connect the GitHub repository; Vercel automatically detects Vite with build command `npm run build` and output directory `dist`.
- **Netlify**: Set build command to `npm run build` and publish directory to `dist`.
- **GitHub Pages**: Deploy the `dist` directory using GitHub Actions or the `gh-pages` package.
- **Cloudflare Pages / AWS Amplify / Firebase Hosting**: Standard single-page application static hosting pointing to the `dist` directory.
